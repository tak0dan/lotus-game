# Contributing

Help is welcome — rules feedback, balance observations, bug reports, ideas, models, cards, lore, code, playtest write-ups, DLC concepts.

## How
- **Ideas and feedback:** open an issue. Playtest findings are especially useful; see `docs/exploits.md` for the format used so far.
- **Changes:** open a pull request. For rules and balance, include what you tested (the simulator is `node test/sim.mjs`; the match server and agent harness are in `tools/`).
- **DLCs and expansions** are welcome and may be published free of charge by anyone, under this same license (see below).
- Read `docs/design-philosophy.md` first: the rules deliberately contain *gaps that reward careful reading* ("dirty play is a feature"). Please ask before "fixing" something that looks unexplained.
