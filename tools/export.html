Export built-in models → .glb

Downloads the code-built reference models. Put them in assets/models/, open them in Blender (or any glTF editor), and save over them — the game picks up whatever file is there. Overwrites your edits if you re-export, so use it once.

Conventions: facing +Z · 1 unit = 1 tile · materials named owner are tinted per player · nodes wing_L wing_R halo flag are animated.
