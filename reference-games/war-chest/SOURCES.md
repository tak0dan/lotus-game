# War Chest — sources
- Rules text used: Yucata's English rules page for the digital adaptation — https://yucata.de/en/Rules/WarChest (faithful to the base game; 4-player mode and some Nobility cards not covered there).
- Publisher: Alderac Entertainment Group (AEG), 2018. The official rulebook is published by AEG; a mirror turned up in search at https://rozum.com.ua/upload/iblock/4e8/5yqrt57bm52dk7w8irxfk50iahm43l53.pdf (third-party host — not copied here).
- Overview pages seen: https://boardgamestories.com/learn-to-play/war-chest/ (video landing page only), https://whatsericplaying.com/2018/10/08/war-chest/ (review).
- **Gaps:** unit card text for several units (Knight, Scout, Swordsman, Royal Guard, full Cavalry), four-player rules, advanced setup details beyond the draft. For exact wording use the physical rulebook/cards.
